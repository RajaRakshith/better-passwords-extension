Better Passwords

The Mac app

Optional and free. It connects your browsers to Apple Passwords in one click, and lets the extension unlock with Touch ID instead of the six-digit code.

Download for Mac Get the extension

macOS 14 or later. Signed and notarized by Apple.

Set it up

  1. Move Better Passwords to Applications and open it.
  2. Click Connect, then turn on Touch ID and allow Accessibility when macOS asks.
  3. Reload the extension.

What it asks for

  • Accessibility, only to read the code in Apple's own code window. Your browser never gets it.
  • Touch ID, every time it enters a code for you.
  • Contacts (optional), only your own card, to suggest your emails in sign-up forms.

It never sees your passwords. How it works

Rather not install an app?

The extension works without it: you connect with one command in Terminal and type the six-digit code instead of using Touch ID.
